## 📋 O que você encontra aqui

### Quiz interativo (`index.html`)
- 115 questões de múltipla escolha, em inglês (como a prova real)
- 5 domínios: Cloud Concepts, Security, Technology & Services, Billing, Integration/Architecture
- Feedback verde/vermelho + explicação em português
- Pontuação em tempo real

### Guia de estudo (`guia.html`)
- Fundamentos de cloud computing (vantagens, Well-Architected, Shared Responsibility)
- Modelos de serviço (IaaS/PaaS/SaaS)
- Visão geral + deep dive dos principais serviços (EC2, Lambda, Containers, Storage, SNS/SQS, VPC)
- Arquitetura completa (como os serviços se conectam)
- Segurança (IAM), Billing e Monitoramento
- Tabela de "pares confusos" (pegadinhas da prova)
- Simulado de 25 questões + banco de 65 questões com gabarito

## 🚀 Como usar

1. Abra o [quiz interativo](https://andressafacundo-maker.github.io/data-learnings/) para praticar.
2. Use o [guia de estudo](https://andressafacundo-maker.github.io/data-learnings/guia.html) para revisar conceitos.
3. Alterne entre os dois: estude no guia, teste no quiz.

## 📌 Sobre o exame

- **Formato:** 65 questões (50 valem nota + 15 não contam)
- **Tempo:** 90 minutos
- **Nota de corte:** ~700 de 1000 pontos
- **Custo:** US$ 100
